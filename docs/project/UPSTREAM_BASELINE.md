The project was forked instead of copying source so that the original Git history,
authorship, license, and engineering context remain intact. Upstream work and university
team additions must remain distinguishable in commits, pull requests, documentation,
and evidence.

The team intends to finish and validate the upstream implementation, then contribute
substantial original Generative AI, Recommender Systems, and Reinforcement Learning
research. Claims present in upstream code or documentation are historical inputs, not
results automatically reproduced by this team. A result becomes reproduced only after
an independent rerun with saved supporting evidence.

## Project terminology

| Category | Meaning |
|---|---|
| **UPSTREAM** | Code or content already present at the frozen baseline. |
| **REPAIRED** | Existing upstream implementation corrected by the team. |
| **COMPLETED** | Intended upstream functionality finished by the team. |
| **EXTENDED** | New functionality introduced by the team. |
| **REPRODUCED** | A claim or result independently rerun and supported by saved evidence. |
| **UNVERIFIED** | Present or claimed in code/docs but not independently established by the team. |
